# AGENTS.md — CourtSweeper HSDD (LaTeX Report)

## Build

```bash
# Full build from repo root (paper.tex expects to run from this directory)
xelatex -shell-escape -output-directory=aux paper.tex
biber --output-directory=aux paper
xelatex -shell-escape -output-directory=aux paper.tex
xelatex -shell-escape -output-directory=aux paper.tex
```

- **Engine:** XeLaTeX (required by `fontspec`, `ctex`, and `minted`)
- **Bibliography:** `biber` via `biblatex` (bib source: `references.bib`)
- **`-shell-escape`** is mandatory — `minted` calls `pygmentize` externally
- All build artifacts go into `aux/`; the final PDF is `aux/paper.pdf`
- `aux/` is fully gitignored (via `aux/.gitignore` containing `*`)

## Project Structure

```

```

## Writing Convention

- **Final target language: English.** Section 4 (`body/4_Detailed_Software_Design.tex`) is currently written in Chinese as an intermediate draft and must be translated to English before final submission.
- All other sections are already in English.
- Use the custom `\ieeesection{Title}` command (not bare `\section`) for top-level section headings; it applies IEEE-style small-caps formatting (large first letter).
- Code blocks use `minted` with `vs` style and Python as the default language.

## Key Packages

- `ctex` — Chinese typesetting support (needed while section 4 is in Chinese; XeLaTeX required)
- `minted` — syntax-highlighted code listings (requires `pygmentize` installed)
- `biblatex` + `biber` — bibliography management
- `fontspec` — system font loading (`Times New Roman`)
- `hyperref` — clickable TOC / citations / URLs
- `tabularx`, `longtable`, `booktabs` — table formatting

## Editing Notes

- When editing a `.tex` file, preserve the existing `\label{sec:...}` anchors — they are cross-referenced across files (e.g., `\ref{sec:hardware}` appears in `1_Introduction.tex`).
- Figures reference paths relative to repo root (e.g., `figures/fig_motor.pdf`).
- The `paper.bbl` file is auto-generated by `biber`; never edit it manually.
